# Two-bead GLE in elastic networks

Codes accompanying the manuscript

**“Exact Generalized Langevin Dynamics of Pair Coordinates in Elastic Networks”**

This repository contains simulation and theoretical-analysis codes for generalized Langevin dynamics of pair coordinates in elastic networks.

## Contents

- [`toy6/`](toy6/)  
  Six-bead elastic-network example used in the main text.

Additional examples may be added later.
